# TMD Daily Excel

ดึงภาพกราฟอัตราการระบายอากาศ 77 จังหวัดจากกรมอุตุนิยมวิทยา อ่านตัวเลขของวันปัจจุบันตามเวลาไทยด้วย Tesseract แล้วสร้าง Excel ไม่ใช้ GPT และไม่ต้องมี API key

## ติดตั้งครั้งแรกผ่านเว็บ GitHub

1. สมัคร/เข้าสู่ระบบ https://github.com แล้วสร้าง New repository ชื่อ `tmd-ventilation` เลือก Public และ Add a README file แล้ว Create repository (Public ทำให้โปรแกรมและข้อมูลที่เก็บถูกเปิดเผย)
2. แตก ZIP นี้บนคอม เปิดโครงการ GitHub แล้วเลือก Add file → Upload files อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ จากนั้น Commit changes อย่าอัปโหลด ZIP และอย่าใส่ไฟล์ซ้อนอยู่ในโฟลเดอร์ `tmd-daily-ready`
3. เปิดไฟล์ `daily.yml` ใน ZIP ด้วย Notepad แล้วคัดลอกเนื้อหาทั้งหมด
4. ใน GitHub เลือก Add file → Create new file ตั้งชื่อให้ตรงว่า `.github/workflows/daily.yml` วางเนื้อหาจากขั้น 3 แล้ว Commit changes เข้า branch หลัก (โดยทั่วไปคือ `main`) การอัปโหลด daily.yml ไว้ที่หน้าแรกเพียงอย่างเดียวยังไม่เปิดระบบ ต้องทำขั้นนี้
5. กดแท็บ Actions → TMD Daily Excel → Run workflow → Run workflow รอขึ้นสีเขียว หากแท็บ Actions ถามให้เปิดใช้งาน ให้เลือกเปิดใช้งาน
6. กลับแท็บ Code เปิดโฟลเดอร์ `data` → `ventilation.xlsx` → กด Download raw file (ปุ่มดาวน์โหลด) เพื่อรับ Excel

หลังจากนี้ระบบจะทำงานวันละครั้ง โดยกำหนดเวลา 09:17 น. เวลาไทย แต่ GitHub อาจเริ่มช้ากว่าเวลา ระบบไม่ต้องใช้คอมของผู้ใช้เปิดทิ้งไว้

## การใช้งานภายหลัง

เปิดโครงการ → `data` → `ventilation.xlsx` → ดาวน์โหลดได้ทุกครั้งที่ต้องใช้ ไฟล์เดียวมีชีต ล่าสุด / ย้อนหลัง / รอตรวจสอบ / คำอธิบาย ข้อมูลสะสมอยู่ใน `data/history.csv` และอัปเดตโดยไม่เพิ่มแถวซ้ำสำหรับวันและจังหวัดเดิม รันซ้ำได้จาก Actions

## ข้อจำกัดที่ควรรู้

- นี่คือข้อมูลพยากรณ์ ไม่ใช่ค่าตรวจวัด ระบุรอบ GFS ในแต่ละแถว
- OCR ไม่รับประกันถูกต้องทุกครั้ง แถวที่อ่านไม่ชัดจะเว้นตัวเลขและระบุรอตรวจสอบ ก่อนใช้ในรายงานสำคัญควรตรวจภาพจากลิงก์ต้นทาง
- ตัวอ่านรองรับภาพขนาด/รูปแบบปัจจุบัน ถ้าผู้ให้บริการเปลี่ยนรูปแบบ ต้องปรับโปรแกรม ไม่อ่านเลขต่อโดยเดา
- รอบรันต้องดาวน์โหลดเว็บต้นทางได้ ถ้าเว็บไซต์ปิดหรือภาพเก่าเกินช่วงพยากรณ์จะระบุรอตรวจสอบ ไม่มีการเติมข้อมูลย้อนหลังที่ไม่เคยเก็บ
- วันที่ที่ระบบไม่ได้รันจะไม่มีข้อมูล ไม่ใช่ศูนย์
- GitHub อาจปิด schedule ของ Public repository ที่ไม่มี activity 60 วัน ตรวจที่ Actions และเปิดใช้งานอีกครั้งเมื่อจำเป็น การสะสมข้อมูลตามปกติจะมีการบันทึกไฟล์ทุกวัน
- ถ้า job บันทึกข้อมูลไม่สำเร็จและขึ้น permission denied ให้ตรวจ Settings → Actions → General → Workflow permissions ให้อนุญาต Read and write permissions หากองค์กรบังคับห้าม ให้ใช้บัญชีส่วนตัวที่อนุญาต
- ไม่ต้องใส่ token, password หรือบัตรเครดิตลงไฟล์โปรแกรม Workflow ใช้สิทธิ์ชั่วคราวของ GitHub ในการบันทึกไฟล์ของโครงการตนเอง
- หากเลือก Private มีโควตานาทีและพื้นที่ตามแพ็กเกจ ควรตรวจ Usage ของบัญชี

## ทดสอบบนคอม (สำหรับผู้ที่ใช้ Python)

ติดตั้ง Python 3.12 และ Tesseract OCR ภาษาอังกฤษ จากนั้น `pip install -r requirements.txt` แล้ว `python collect.py` โหมดตรวจภาพที่ดาวน์โหลดไว้ใช้ `python collect.py --date YYYY-MM-DD --cache-dir /path/to/images` โหมดนี้ไม่เหมาะกับการเก็บย้อนหลังโดยไม่มีภาพของวันจริง

Station list checked 2026-10-20. Nonthaburi uses 411000; Nakhon Pathom uses 451301.
